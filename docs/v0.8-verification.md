# SukaWallet 0.8.0 真机验证

设备：peridot，Android 16 / HyperOS 3。正式包名 `top.suzuki.sukawallet`。

## 本次修复

手势设置和验证共用正方形网格，以视图宽高中较短的一边计算横纵坐标，并居中绘制。触摸命中与绘制使用相同坐标。点和线宽随密度缩放。

设置页内联显示外观与保护方式的下拉选项；下拉箭头为矢量，展开时旋转。选项弹层在大字号时可滚动。首页刷卡按钮位于底部；右上角三点按返回箭头的尺寸规则和对称边距排列。

## 手势交互

诊断包通过 Activity 触摸事件分发验证短图案拒绝、两次确认、不匹配重设、保存、错误图案拒绝和正确图案解锁。均通过。此检查不依赖系统级触摸注入；系统级注入在该设备未可靠触达页面。
